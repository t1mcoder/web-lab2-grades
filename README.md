# Лабораторная работа 2

Анализ успеваемости. Работа с Git и Pull Request в GitHub.

Выполнил: Манасян Тимофей, группа ОВБИ-301б.

Работа выполняется индивидуально с одной учётной записью, как разрешил преподаватель. Проверка кода проводится самостоятельно.

## Программа

В `main.js` находятся исходный массив и четыре функции:

- `calculateAverage(data)` — средний балл, для пустого массива `null`.
- `findTopStudent(data)` — имя лучшего студента, для пустого массива `null`. При равенстве баллов выбирается первый.
- `filterFailed(data, passScore = 60)` — имена студентов с баллом строго ниже проходного.
- `addLetterGrade(data)` — добавляет каждому объекту поле `letter`: A при балле от 90, B от 75 до 89, C ниже 75. Изменяет переданный массив, как предусмотрено заданием.

`report.js` вызывает все функции и печатает результаты в консоль.

## Запуск

Нужен Node.js 18 или новее. Внешние зависимости не используются.

```sh
node report.js
node --test
```

Ожидаемый результат для заданного массива:

- средний балл — 77.6;
- лучший студент — Денис, 92 балла;
- не сдал — Студент_X, 45 баллов;
- буквенные оценки: Макар B, Денис A, Анна B, Даша B, Студент_X C.

## Работа с ветками

Изменения программы вносятся в `feature/timofey`, затем предлагаются через Pull Request в `develop`. После самостоятельной проверки и слияния оформляется отдельный Pull Request из `develop` в `main`. Фактические PR и коммиты доступны во вкладке Pull requests и в истории репозитория.
